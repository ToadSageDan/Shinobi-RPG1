# Assets Guide — Sourcing Art for Shinobi RPG

All code, shaders, scenes, game logic, UI, VFX, and audio wiring are complete for **v0.6.0**.
The game is fully playable right now using procedural placeholder assets (PlaceholderRig.gd,
BiomeTerrain.gd, AffinityVFX.gd). This guide shows how to upgrade each placeholder with
real free art assets — no payment needed.

---

## v0.6.0 Placeholder Status

| System | Placeholder | To upgrade |
|--------|-------------|------------|
| Characters | `PlaceholderRig.gd` (primitive meshes) | Add Mixamo FBX + AnimationPlayer |
| Terrain | `BiomeTerrain.gd` (coloured boxes) | Import real terrain meshes per biome |
| Jutsu VFX | `AffinityVFX.gd` (gradient particles) | Add texture sprites to the GPUParticles3D |
| Audio | Silent (AudioManifest gracefully skips missing files) | Add `.ogg`/`.wav` to `res://assets/audio/` |
| Quest Markers | `QuestWaypoint.gd` (spinning box + beam) | Replace IconMesh with a real icon mesh |

## Characters

### Free Option — Mixamo (recommended starting point)
1. Go to [mixamo.com](https://www.mixamo.com/) (free with Adobe account)
2. Download a ninja/character base mesh in **FBX for Unity** format (works in Godot too)
3. Download animations: idle, run, jump, attack (light/heavy), dodge, death, hurt
4. Import into Godot via **Import > Scenes** — use the FBX importer
5. Add the imported `MeshInstance3D` and `AnimationPlayer` under `scenes/characters/Player.tscn`
6. Delete the `PlaceholderRig` child node — the scripts will automatically use the real mesh

Animation names to map (Player.gd `_play_anim` calls):
- `idle`, `run`, `jump`, `fall`, `land`
- `dash`, `dodge`
- `wall_run_left`, `wall_run_right`, `wall_jump`, `double_jump`
- `attack_1`, `attack_2`, `attack_3`, `attack_heavy`, `attack_air`
- `hurt`, `death`
- `jutsu_charge`, `jutsu_fire`, `jutsu_fail`, `chakra_charge`
- **Boss only:** `boss_signature`, `boss_defeat_kill`, `boss_defeat_charm`,
  `boss_defeat_stealth`, `boss_defeat_evasion`

### Other Free Options
- **Godot Asset Library**: search "ninja", "shinobi", "character pack"
- **Itch.io**: many free/CC0 character asset packs — search "ninja character 3d"
- **KayKit** (kaylousberg.com): clean stylized packs, CC0 license

### Arena Floor Setup (Godot)
`BiomeTerrain.gd` already builds a playable placeholder layout at runtime.
To upgrade to real terrain for a specific arena:
1. Import your terrain mesh as a `MeshInstance3D` under the arena root
2. Add a `StaticBody3D` + `CollisionShape3D` for physics
3. Remove the `ScatterObjects` and `Walls` nodes generated by `BiomeTerrain`
   (or set `BiomeTerrain.build(self, region_key)` to only run when no real mesh is detected)

## VFX Particles

`AffinityVFX.gd` already configures `GPUParticles3D` automatically per affinity using
procedural `ParticleProcessMaterial` with gradient color ramps and shaped emitters.

To enhance the VFX with sprite sheets:
- Add a `texture` PNG sprite sheet (e.g. fire/smoke from opengameart.org) as the
  `GPUParticles3D.draw_pass_1` mesh override, or set `ParticleProcessMaterial.color_ramp`
  to a `GradientTexture1D` pointing to your custom texture.
- Free particle sprites: https://opengameart.org/content/particle-pack (CC0)

## Audio

All audio keys are now registered in `AudioManifest.gd`. The game runs silently until
you add files — no code changes needed, just drop files in the right folders.

Required audio keys (referenced in `AudioManifest.gd` and `AudioManager.gd`):

### File layout
```
res://assets/audio/
  music/
    menu_theme.ogg
    forest_theme.ogg
    volcanic_theme.ogg
    coastal_theme.ogg
    alpine_theme.ogg
    cave_theme.ogg
    boss_intense.ogg
  sfx/
    hit_fire.wav   hit_water.wav  hit_earth.wav  hit_wind.wav
    hit_generic.wav  sfx_death.wav  sfx_dodge.wav  sfx_dash.wav
    sfx_jutsu.wav    sfx_level_up.wav
```

### Music (looping .ogg)
| Key                    | Description                        |
|------------------------|------------------------------------|
| `music_menu`           | Title screen ambient               |
| `music_forest`         | Verdant Gate exploration            |
| `music_volcanic`       | Ashen Cradle battle                |
| `music_coastal`        | Tideglass exploration              |
| `music_alpine`         | Stormwall Ridge battle             |
| `music_cave`           | Sunken Hollow ambient              |
| `music_boss_phase2_*`  | Intensity layer for each boss      |

## Registering Audio in Godot

After adding your audio files to `res://assets/audio/`, register them in your
arena's `_ready()` or in an `AudioManifest.gd` autoload:

```gdscript
AudioManager.register_streams(
    {
        "music_forest": "res://assets/audio/music/forest_theme.ogg",
        "music_boss_phase2_kage_renda": "res://assets/audio/music/boss_intense.ogg",
    },
    {
        "hit_fire": "res://assets/audio/sfx/hit_fire.wav",
        "sfx_death": "res://assets/audio/sfx/death.wav",
        # ...
    }
)
```

## Applying the Cel-Shading Material

1. Select a character mesh in the Godot editor
2. In the `Surface Material Override` slot, create a new `ShaderMaterial`
3. Set shader to `res://resources/shaders/cel_shading.gdshader`
4. Tune `albedo_color`, `affinity_tint`, and `affinity_tint_strength`
   to match each character's elemental theme

## Minimum Viable Art Pass (to get running first)

You can launch and play the game **without any art assets** using Godot's built-in
primitive meshes. The game logic, combat, and all systems are fully functional.
Replace meshes gradually as you source art.
