# Contributing to Shinobi-RPG1

Thanks for contributing.

## Development setup

1. Use Python 3.12+.
2. Install project dependencies if needed.
3. Run tests:

```bash
python -m unittest discover -s tests -p "test_*.py"
```

## Contribution process

1. Create a focused branch for your change.
2. Keep changes scoped and include tests for behavior updates.
3. Make sure tests pass before opening a PR.
4. Write clear PR descriptions that explain what changed and why.

## Code style

- Prefer small, readable functions.
- Keep game-balance changes explicit in code and tests.
- Avoid unrelated refactors in feature/fix PRs.
